# tessera-visual

Spatial pieces for any web app: image annotation and a whiteboard, and maps with clustering and
location picking. Part of the [Tessera](https://github.com/thakurabhishek7283/tessera) kit family.

Work in progress.

## Development

```sh
pnpm deps       # clones and builds tessera into external/
pnpm install
pnpm check
```
